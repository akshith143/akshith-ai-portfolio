# Voice samples (git-ignored)

Drop recordings of **your own voice** here, then run `npm run clone-voice`.

For a clone that sounds like you rather than a generic voice:

- **1–3 minutes total** is the sweet spot for ElevenLabs Instant Voice Clone. More isn't better past ~3 min.
- Talk the way the site will talk: answer interview questions out loud ("Tell me about yourself", "What did you do at OneCard?"). Conversational, not read-aloud.
- Quiet room, phone or laptop mic ~20 cm away, no music, no echo. One speaker only.
- `.mp3`, `.wav` or `.m4a`. A few 30–60 s files is fine.

The files never leave your machine except for the upload to ElevenLabs, and they're excluded from git.
